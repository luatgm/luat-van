# Thiệp cưới lật trang – Minh Luật & Đỗ Vân

Hai trang độc lập: `nha-trai.html` và `nha-gai.html`. Trang `index.html` để chọn thiệp. Có 3 lượt xem: bìa/lời mời, thông tin/lịch trình, gia đình/địa chỉ QR. Bấm mũi tên, nút Lật thiệp hoặc vuốt ngang.

## Đưa lên GitHub Pages
Giải nén và tải **các file bên trong thư mục** lên repository `luatgm/thiep-cuoi-luat-van` (không tải nguyên ZIP). Nếu GitHub báo file đã tồn tại, cập nhật/ghi đè bản cũ. Bật Settings > Pages > Deploy from a branch > main > /(root).

- `https://luatgm.github.io/thiep-cuoi-luat-van/nha-trai.html`
- `https://luatgm.github.io/thiep-cuoi-luat-van/nha-gai.html`

## Tên khách riêng
Thêm `?to=Anh%20Hieu` vào cuối đường dẫn của từng thiệp. Tên khách hiện trên thiệp; không có khung nhập tên trong thiệp.

QR sử dụng các ảnh QR đã gửi. Vui lòng thử quét trên điện thoại để kiểm tra vị trí trước khi gửi khách.

## Responsive v2
Trên màn hình <=700px thiệp hiển thị từng trang riêng (6 trang), trên màn hình lớn hiển thị 2 trang (3 lượt lật). Có thể vuốt ngang hoặc bấm mũi tên.

# Thiệp cưới Minh Luật & Đỗ Vân — phiên bản lật từng trang

- `nha-trai.html`: thiệp nhà trai
- `nha-gai.html`: thiệp nhà gái
- Một trang duy nhất hiển thị mỗi lần trên cả máy tính và điện thoại.
- Lật trang với hiệu ứng 3D bằng nút, phím mũi tên hoặc vuốt ngang.
- Trang cuối chứa địa chỉ và QR chỉ đường.
- Cá nhân hóa tên khách qua `?to=Anh%20Hieu`.
